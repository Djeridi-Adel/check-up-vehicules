Règles appliquées automatiquement
  • Un agent ne peut pas travailler le dimanche s'il travaille le samedi précédent ou le samedi de la semaine suivante.
  • Un agent en vacances la semaine du dimanche n'est pas éligible.
  • Chaque poste exigeant une compétence ne peut être tenu que par un agent qui la possède.
  • Un agent avec une restriction sur un poste ne peut pas y être affecté.
  • Seuls les volontaires peuvent être affectés, un seul poste par agent et par dimanche.
  • La répartition automatique privilégie les agents ayant fait le moins de dimanches.
